# GUI 中英文切换修改版

基于当前 `D:\Uni-Master\Study\EE6008\git\voice-control-gui` 中的代码制作。
当前任务没有该目录的写入权限，因此此文件包尚未覆盖实际项目。

## 使用

1. 关闭运行中的程序，并备份项目中的 `main_voice_app.py` 和 `gui_theme.py`。
2. 将本目录的三个 Python 文件一起复制到项目根目录：
   - `main_voice_app.py`：主界面和翻译连接。
   - `gui_theme.py`：顶栏左侧新增与 Ready 同款的“中/EN”按钮。
   - `ui_language.py`：新增翻译目录及界面翻译工具。
3. 按原来的方式运行 `main_voice_app.py`。无需安装新的依赖。

## 切换行为

- 启动时默认英文，点击“中/EN”切换中文，再点一次恢复英文；按钮文字始终为“中/EN”。
- 切换覆盖窗口标题、四个页面、按钮、表头、识别状态、系统状态、健康报告和弹窗。
- 切换后到来的实时状态也会使用当前界面语言。
- 当前标签页、输入、选中的命令以及开始/停止按钮的启用状态保持不变。
- Activity Log 中已有及后续日志都保持原文，保存日志的内容也不因语言切换改变。
- NTU 标识、命令文本、模型名、声线名、文件路径等数据保留原值；外部库的原始诊断详情保持原文。
- 只切换显示语言，不改变 Whisper 语言、唤醒词、命令映射、输出文件或 TTS 播报。
- 本次未增加语言设置持久化；重新启动仍默认英文。
